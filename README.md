# Yad Terapia Oral

Sitio web para catálogo y asesoría de herramientas de terapia oral y motora (TalkTools® / ARK Therapeutic).

## Stack

- TanStack Start
- TypeScript
- React
- Tailwind CSS

## Desarrollo local

Requiere Node.js (o Bun) instalado.

```sh
bun install
bun run dev
```

## Build de producción

```sh
bun run build
```

Esto genera los archivos listos para desplegar en cualquier hosting compatible con Node.js / servidores estáticos + SSR (Vercel, Netlify, servidor propio, etc.).
